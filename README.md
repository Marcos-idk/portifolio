# Portfólio de Marcos Santos

Versão atualizada do portfólio pessoal com visual minimalista em preto e branco.

## O que mudou
- Interface mais limpa e com menos informação na tela.
- Nova paleta monocromática (preto, branco e cinza).
- Projetos organizados por abas: NASA, pessoais e acadêmicos.
- O projeto **Doe+** agora possui uma página com visual próprio, parecendo um software separado do restante do portfólio.

## Estrutura
- `index.html` — página inicial do portfólio
- `styles.css` — estilos globais e da página do Doe+
- `script.js` — interação das abas
- `theme.js` — alternância de tema do portfólio
- `projetos/doe-mais.html` — apresentação própria do Doe+
- `downloads/doeplus-java.zip` — código-fonte Java do Doe+

## Como usar
1. Abra `index.html` no navegador.
2. Para hospedar no GitHub Pages, envie o conteúdo desta pasta para a raiz do repositório.
3. O arquivo `index.html` precisa ficar na raiz do repositório.
